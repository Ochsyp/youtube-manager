{# The status vocabulary in one place: status_label(status) renders one effective status, colouring the transient ones and title-casing everything else, so no view spells a state its own way. Imported as `status` wherever a job is shown; takes no page context. #} {% macro status_label(status) %} {% if status == 'expanding' %} Expanding... {% elif status == 'metadata' %} Fetching metadata {% elif status == 'cancelling' %} Cancelling... {% elif status == 'cancel requested' %} Cancel requested {% else %} {{ status.capitalize() if status else '-' }} {% endif %} {% endmacro %}
